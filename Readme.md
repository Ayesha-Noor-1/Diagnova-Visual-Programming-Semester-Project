# Diagnova

### AI-Powered Symptom Assessment & Doctor Recommendation System

## Overview

Diagnova is an intelligent medical assistance platform designed to provide preliminary symptom analysis and guide users toward the most appropriate healthcare specialist.

## Features

* Symptom-based health assessment
* AI-powered preliminary disease prediction
* Smart doctor recommendations
* User-friendly interface
* Fast and accessible healthcare guidance

## Purpose

The purpose of Diagnova is to assist users in understanding potential health concerns and connect them with the right medical professionals efficiently.
